링크 넣는 방법

이 파일을 메모장이나 편집기로 열어 아래쪽 LINKS 부분에 각 장의 주소를 넣으세요. 비어 있는 장은 점선 카드로 표시되고 눌러도 이동하지 않습니다. 같은 폴더에 파일을 두었다면 파일 이름만 적어도 됩니다.

var LINKS = {
  1: "",                                    <- 아직 비어 있음
  2: "ch02_판다스_패키지_핸즈온랩.html",        <- 같은 폴더의 파일
  3: "https://example.com/ch03.html"        <- 인터넷 주소
};
